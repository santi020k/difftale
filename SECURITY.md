# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Difftale. Please
update to the newest release before reporting an issue that may already be
resolved.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/santi020k/difftale/security/advisories/new)
for suspected vulnerabilities. If that is unavailable, email
<hi@santi020k.com> with the repository name and a concise description.

Do not open a public issue for an unpatched vulnerability. You can expect an
initial acknowledgement within seven days. Fix timing depends on severity and
the scope of the affected release.

For ordinary bugs, feature requests, or accessibility issues that do not expose
sensitive data or unsafe behavior, use the public issue tracker instead.
